## 3. Tiga Cara Menggunakan Paket Ini di Canva

### Cara 1: Impor Langsung File SVG ke Canva (Editable Vector)
1. Buka [Canva](https://www.canva.com).
2. Klik tombol **Unggah** (*Upload*) di panel kiri, lalu pilih file SVG dari folder `canva/mockups/` (misalnya `social-media-post.svg` atau `desktop-homepage.svg`).
3. Canva akan memproses file SVG menjadi elemen desain Canva.
4. Seret (*drag*) hasil unggahan ke lembar kerja kanvas baru.
5. Elemen bentuk, warna pengisi (*fill color*), dan susunan kelompok dapat disesuaikan langsung di Canva.

### Cara 2: Menggunakan PNG Previews Sebagai Lapisan Dasar (Pixel-Perfect Guide)
1. Buat kanvas baru di Canva dengan dimensi yang sesuai:
   - Untuk desktop: Buat desain ukuran khusus `1440 × 4300 px` atau gunakan template *Canva Website*.
   - Untuk mobile: Buat ukuran khusus `390 × 4200 px`.
   - Untuk media sosial: Buat kanvas `1080 × 1080 px`.
2. Unggah file PNG dari folder `canva/previews/` ke Canva.
3. Letakkan PNG sebagai gambar latar (*background*).
4. Tambahkan tombol interaktif bawaan Canva (*Canva Link Elements*) atau kolom formulir langsung di atas visual tersebut.

### Cara 3: Membuat Ulang di Canva Website Menggunakan Panduan Merek
1. Pilih template **Canva Website** di Canva.
2. Buka file `canva/brand-guide.md` sebagai rujukan utama.
3. Masukkan kode HEX resmi untuk warna latar (`#F7F8F3`), warna tombol primer (`#B6F084` dan `#06180E`), dan kartu (`#FFFFFF`).
4. Unggah logo `canva/assets/bumiloka-logo.webp` ke bagian header.
5. Gunakan font **Plus Jakarta Sans** atau **Inter** untuk teks judul dan paragraf.

## 4. Batasan Teknis Impor SVG di Canva (Transparansi Teknis)

Harap perhatikan karakteristik penanganan file SVG oleh platform Canva:
- **Teks SVG**: Tergantung browser dan versi akun Canva, elemen teks SVG tertentu dapat diimpor sebagai teks yang dapat diketik ulang, atau dikonversi menjadi bentuk vektor kurva (*vector outlines/paths*). Jika Anda memerlukan pengeditan teks dinamis secara menyeluruh di Canva, gunakan file PNG di folder `canva/previews/` sebagai panduan posisi, lalu ketikkan teks baru menggunakan alat teks bawaan Canva dengan font *Plus Jakarta Sans*.
- **Foto & Logo**: File SVG menyertakan aset gambar (logo dan foto kebun) menggunakan *data URI base64* terintegrasi. Hal ini memastikan gambar tidak akan hilang atau *broken* saat file SVG dipindahkan antar folder atau diunggah ke Canva.
- **Rasio Kanvas Panjang**: Canva Website membagi halaman panjang menjadi beberapa blok/halaman seksi. Jika ingin membuat website Canva interaktif multi-halaman, Anda dapat memotong desain per seksi (masing-masing setinggi ~600–900px).
